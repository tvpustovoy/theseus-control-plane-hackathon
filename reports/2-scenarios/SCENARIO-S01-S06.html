Через все кадры проходит одна цепочка записей: встреча → мандат v1 → закономерность → проверка SubQ → предложение v2 → активация → прогоны симуляции. ID возьмём у Argon, когда экраны заработают. Ролик на 60 секунд собирается из тех же кадров, по 8 секунд на экран.

Чего не хватает к записи

  1. Шесть экранов у Argon ещё строятся. Снимать нечего, пока нет адреса localhost и маршрутов.
  2. Валидации поля в демо-CRM для S05 ещё нет.
  3. Симуляция для S06 считается, но прогонов в MongoDB и графика пока нет.
  4. Карточки Fetch и переход из них на сайт не проверены.
  5. Реальные ID записей и эпизод с источником слов Владимира — от Argon и Muse перед записью.
