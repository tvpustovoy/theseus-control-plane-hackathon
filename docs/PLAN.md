## Две фазы

**A. Первичная подготовка.** Первичный слой RecPlace → проверенная копия как есть в MongoDB → детерминированный индекс sources → новое извлечение Meta → утверждения с цитатами → сверка кандидатов SubQ → решение владельца → исходная версия модели → первый исполняемый инструмент. Старые готовые факты не подменяют новое извлечение.

Точки входа: [Argon](agents/argon/START-HERE.md), [Muse](agents/muse/START-HERE.md). Первый общий контракт — [INGESTION-CONTRACT.md](../database/INGESTION-CONTRACT.md), источник — [RECPLACE-SOURCES.md](RECPLACE-SOURCES.md).

**B. Управление в цикле.** Новый материал или результат работы → только изменившиеся данные → новые/изменённые утверждения → влияние на правила, обязательства, инструменты и агентов → решение → изменение кода/навыка → независимая проверка → принятие или откат → наблюдение поведения.

Код извлечения общий для обеих фаз. На входе второй фазы он работает с дельтой и сохраняет связи с предыдущей версией. Новая запись не стирает старую, новый источник не становится правилом автоматически.

## Порядок открытия работ
1. **Сейчас:** Тарас проверяет план. Задачи и владельцы в трекере — предложения, не автоматическая выдача.
2. **После разрешения:** координатор утверждает контракты, границы записи и проверочный набор; новые сессии подтверждают идентичность и готовность. Проверяется доступ к API.
3. **Параллельно:** Argon делает схему/adapter и raw-импортёр; Muse — chunker и извлечение на synthetic fixture. SCHEMA_READY открывает интеграцию writer; RAW_IMPORT_VERIFIED открывает реальный pilot Meta. Deputy CEO — следующий этап. Независимый проверяющий назначается отдельно.
4. **Сборка A:** соединяем реальные вызовы Meta/SubQ/MongoDB, согласуем начальную модель и запускаем один инструмент.
5. **Сборка B:** добавляем один новый материал, показываем изменение модели, решение владельца и изменение инструмента.
6. **Доказательство:** новая версия навыка/контекста улучшает результат на отложенных случаях; плохое изменение блокируется; откат проверен.
7. **Защита:** Setu заменяет места для доказательств реальными результатами. Публикация и сдача идут отдельным явным действием.
